ドット絵のストーリーゲーム『線香花火の夜に』を作った話

2026.08.06

こんにちは、せいめいです。ポートフォリオに新しい作品を追加しました。 『線香花火の夜に』という、10分くらいで遊べるドット絵のストーリーゲームです。 ブラウザでそのまま遊べますので、 この記事を読む前でも後でも、ぜひ触ってみてください。

きっかけは単純で、「昔遊んだ『ぼくのなつやすみ』みたいな、夏の空気のゲームを自分のサイトに置きたい」と思ったことです。 勇者がスライムを倒す王道RPGよりも、ストーリーがあって、ちょっと不思議で、 最後に心があたたかくなるような小さな作品にしたい。そんなイメージから始まりました。

内容は、夏休みにおばあちゃんの村に預けられた男の子が、神社で不思議な女の子と出会う……というお話です。 昼はのどかな村を歩き、夕方にはホタルを追いかけ、夜にはお祭りが始まります。 少しだけ怖い場面もありますが、怖がらせること自体が目的ではなくて、 最後まで遊ぶと意味が分かるようになっています。ネタバレになるので、これ以上は書きません。

技術的には、今回もHTML / CSS / JavaScriptの1ファイル構成にこだわりました。中身はこんな感じです。

  • Canvasによるタイルマップ描画とドット絵キャラクター（画像素材は使わず、全部コードで描いています）
  • 会話ウィンドウと選択肢システム（エンディングの台詞が変わる分岐つき）
  • 昼→夕方→夜と移り変わる光の演出
  • Web Audioで自作したチップチューンBGM。場面に合わせて5曲が自動で切り替わります
  • スマホのタッチ操作対応（画面に十字キーとボタンが出ます）

正直に書くと、この作品は相棒のAIと二人三脚で作りました。 「こういう雰囲気にしたい」「この場面はもっとこうしたい」という方向性やジャッジは自分が出して、 実装の手を動かすのはAIに任せる。この分業だと、思いついたその日に動くものができあがります。 1人と1AIの小さな制作体制ですが、だからこそ出せるスピード感だと思っています。

あわせて、Worksページの各作品に「♥ いいね」ボタンを付けました。 遊んでみて「よかったな」と思ったら、ポチッと押してもらえるととても励みになります。

夏の終わりの、線香花火のようなささやかなゲームです。 10分だけ、あの村の夕暮れを歩いてみてください。

【追記】ゲームの世界観を切り取ったスマホ壁紙（全3枚）の無料配布も始めました。 こちらもドット絵をすべてコードで描いた自作です。よければお持ち帰りください。
