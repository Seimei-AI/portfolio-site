AI社員と、コツコツ事業を作っています！

個人投資家・Web制作 安倍清明

できること

HTML / CSS / JavaScriptを使ったホームページ・ランディングページの制作から、 既存サイトの修正・機能追加まで、AI社員との分業でスピーディに形にしています。 投資歴3年の知識を活かした投資系ジャンルのサイトづくりも得意分野の一つです。

  • ホームページ制作（企業サイト・個人サイト）
  • ランディングページ（LP）の新規制作
  • 既存サイトの修正・更新・機能追加
  • スマホ対応（レスポンシブデザイン）

制作で大事にしていること

  • 表示速度・スマホでの見やすさを最優先に考える
  • AIを活用した制作体制により、スピーディかつ丁寧な対応を心がける
  • 進捗はこまめに共有し、認識のズレが出ないようにする
