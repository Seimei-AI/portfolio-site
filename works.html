ブラウザゲーム（リズムゲーム）

リズムゲーム『NEON BEAT』

落ちてくるノーツをタイミングよくキャッチする、4レーンの音楽ゲームです。 BGMはWeb Audioでコード進行から自作したチップチューン3曲（ポップ／疾走系／チル）で、 譜面は曲のメロディから自動生成。画面の端ではキャラクターがビートに同期して踊り、プレイの調子に合わせて表情が変わります。 HTML / CSS / JavaScriptの1ファイルで実装（キーボード＆スマホのタップ操作対応・難易度3段階）。

ストーリーゲーム『線香花火の夜に』

ドット絵の村を歩いて物語を進める、探索型のショートアドベンチャーです。 タイルマップ描画、会話・選択肢システム、昼→夕→夜と移り変わる光の演出、Web Audioで自作したチップチューンBGM・効果音までを HTML / CSS / JavaScriptの1ファイルで実装。プレイ時間は約10分。 少し不思議で、最後に心が温まる夏のお話です（スマホのタッチ操作にも対応）。
